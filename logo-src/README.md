# Logo
`/logo-tlc.svg` (navy and gold, for light backgrounds) and `/logo-tlc-dark.svg` (white and light gold, for navy backgrounds) are the wordmark
'THE LOCAL' over 'Cabinetry' with the letters converted to outlines, so they need no font. Built by `build_logo.py` from two SIL OFL fonts:
Fraunces (Cabinetry, weight 600) and Hanken Grotesk (THE LOCAL, weight 700); their licence texts are next to this file.
To rebuild, put the two variable TTFs from github.com/google/fonts (ofl/fraunces, ofl/hankengrotesk) in this folder and run `python3 build_logo.py`.
