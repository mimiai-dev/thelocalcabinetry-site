# The Local Cabinetry brand kit

1. `logos/`: PNG 2000 px transparent and SVG (wordmark light and dark background; monogram gold, navy, white; avatars).
2. `fonts/`: Fraunces and Hanken Grotesk (OFL), TTF and woff2, licences included.
3. `BRAND-GUIDE.md`: voice, approved claims, words to avoid, visual style, colors (hex, use, contrast), image rules, content preferences, priorities.
4. `ASSETS.md`: finish sheets, catalogs, cleared photos, pages to link.
5. `CONTENT-PLAN.md`: content pillars and the first 2 weeks of posts.
6. `finish-sheets/`, `catalog/`, `photos/`: the files themselves.

Monogram note: the TLC monogram was redrawn as a vector from the approved 512 px artwork (overlap with the original 99.99%); the colors are gold #d8b25c, navy #0e2740, white.
